# Netflix Movies and TV Shows Data Cleaning

## Project Description
This mini project cleans the Netflix Movies and TV Shows dataset using Python and Pandas.

## Tasks Performed
1. Loaded the Netflix dataset.
2. Checked missing values.
3. Checked duplicate records.
4. Filled missing director, cast, and country values with "Unknown".
5. Removed records missing rating or duration.
6. Removed duplicate records.
7. Converted date_added into datetime format.
8. Exported the cleaned dataset as netflix_cleaned.csv.

## Tools Used
- Python
- Pandas
- GitHub Codespaces
